## 🌟 Features & Highlights

### 🌌 1. 3D Night Sky & Fireworks Canvas (Three.js)
- **Tap anywhere** in the sky to launch multi-colored 3D fireworks, glowing Kamuro golden willows, and glitter bursts.
- **Floating 3D Diyas & Akash Kandils**: 10 hand-sculpted clay diyas floating in an arc, undulating gently with dynamic flame lights that illuminate the night fog.
- **Release Sky Lanterns (Akash Kandils)**: Send glowing hot-air lanterns floating into the starry heavens.
- **Interactive Crescent Moon Easter Egg**: Tap the moon 5 times to unlock a secret 3 AM GC Bakchodi achievement mode!

### 🔥 2. The GC Friends Wall (All 10 Legends)
- **3D Card Flip**: Tap any card to flip between their affectionate **Diwali Roast** and heartfelt **Festive Blessing**.
- **Interactive 3D Tilt**: Cards tilt naturally in 3D following your cursor or mobile touch.
- **💥 Send Patakha**: Blast animated sparks and sutli bombs onto any friend's card with real-time counters.
- **📋 Copy Roast & 📲 WhatsApp Direct Share**: Instant pre-formatted sharing to WhatsApp with custom emojis for rapid group chat banter.
- **🎲 Roast Roulette**: Randomly pick a friend to put in the hot seat.

### 🌸 3. Sacred Laxmi-Ganesh Puja Mandap
- **🔔 Ring Brass Temple Bell**: Auspicious harmonic chime synthesis with physical swinging animation.
- **🌸 Pushpanjali Offering**: Shower fresh marigold and lotus petals onto the sacred altar.
- **🪔 Aarti Ceremony**: Sacred orbiting Aarti thali with camphor flame and Vedic bells.
- **Incense Smoke Wisps**: Delicate curling agarbatti smoke rising by the altar.

### 🍬 4. Interactive Shahi Mithai Box
- **Royal 3D Box Unboxing**: Pop open the velvet red & gold gift box to reveal freshly made Indian sweets:
  - 💎 *Silver Kaju Katli* (with silver leaf vark)
  - 🟠 *Motichoor Ladoo* (pure desi ghee)
  - 🍯 *Hot Gulab Jamun*
  - 💚 *Shahi Pista Barfi*
  - 🥨 *Crispy Kesar Jalebi*
  - 📦 *Legendary Soan Papdi* (The historic pass-along box)
- Sweets crunch and burst into sparkles when eaten with group-specific punchlines!

### 🎨 5. 3D Rangoli Studio
- Pick from 8 traditional gulal pigments (Kumkum Red, Haldi Gold, Marigold Orange, Peacock Blue, Rani Pink, etc.).
- Tap mandala rings to paint with powder splash particle effects.
- **Magic Rainbow Fill & 3D Tilt/Spin**: Tilt the courtyard rangoli into 3D isometric view or rotate it 360°.

### ✨ 6. Virtual Phuljhari (Handheld Sparkler)
- Toggle on the Phuljhari mode to drag a sizzling, crackling Diwali sparkler across your screen that leaves dazzling golden light trails!

### 🔊 7. Synthesized Web Audio API (Zero External Dependencies)
- 100% generated in real-time using mathematical oscillators and noise buffers — **never fails or 404s** on mobile.
- Temple bells, sitar glissando, firework whistling rockets, booming bursts, and serene background tanpura drone.

## 🚀 One-Click Deploy to Vercel

### Option 1: Automatic (Recommended)
1. Click the button below:  
   [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Extreme747/GC-diwali)
2. Connect your GitHub account and click **Create**.
3. Vercel will instantly build and deploy your project with a live global URL!

### Option 2: Via Vercel CLI
```bash
# Install Vercel CLI globally
npm i -g vercel

# Deploy in seconds
vercel
```

### Option 3: Local Development
```bash
# Clone the repository
git clone https://github.com/Extreme747/GC-diwali.git
cd GC-diwali

# Serve locally
npx serve .
# Or simply double-click index.html to open in any modern browser!
```
